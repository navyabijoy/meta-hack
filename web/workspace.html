Try it

Drop a screen recording

A plain recording of a bug in your app, ideally from a freshly loaded page. Saying what you expected out loud helps.

What happens next

Gecko watches the recording, replays it in a real browser, and writes a test that fails the same way. Then Muse Code writes a fix, and Gecko only keeps it if the test passes and your suite stays green.
